# Current HSBTE Curriculum Layer

This directory contains only curriculum records that have been verified against current HSBTE sources.

## Verification rule
The current HSBTE Computer Engineering page exposes detailed content links for Semesters 1–6. HSBTE's homepage also currently references the 2022-23 curriculum and the Scheme 2022 second-year curriculum. Because HSBTE also hosts historical Computer Engineering curricula, this project does not copy historical subject lists into the current scheme without explicit source support.
