# ByteCore

A professional, open-source learning platform for the current HSBTE Computer Engineering Polytechnic curriculum in Haryana, India.

## Foundation direction

ByteCore is designed as a **knowledge system first, learning tool second, spatial experience third**. The interface uses technical geometry, premium typography, restrained depth and purposeful motion rather than generic neon/glassmorphism.

## Current branch

`feature/bytecore-foundation`

The foundation currently contains:

- Academic Command Center homepage
- Spatial ByteCore Core visual with adaptive CSS rendering
- Responsive navigation and touch-friendly layouts
- Local-first global-search interaction shell
- Semester navigation shell for Semesters 1–6
- Academic Vault with explicit verification states
- Notes / PYQ / Practice / AI Tutor / Resources / Open Source information architecture
- Lightweight PWA manifest and service-worker shell
- No frontend API keys or secrets

## Content integrity

Official HSBTE curriculum remains the source of truth. Do not invent subjects, subject codes, units, topics, exam metadata or official papers. User-provided material must be labeled as user-provided, verified external material must retain provenance, and generated practice must never be presented as an official PYQ.

## Next implementation phases

1. Verify the current HSBTE Computer Engineering scheme from authoritative material.
2. Add the normalized content schema and validation scripts.
3. Process the supplied PYQ archives with relevance, duplicate and metadata checks.
4. Build subject/unit/topic readers and the professional PDF viewer.
5. Add local progress, bookmarks, recent activity and study workspace.
6. Add the provider-independent AI Tutor interface and secure future backend boundary.
7. Add production PWA caching, search indexing, accessibility checks and GitHub Pages deployment workflow.

## Design rule

3D and motion must improve orientation, understanding or navigation. When visual complexity needs to reduce, preserve the ByteCore visual language rather than replacing it with a generic interface.
